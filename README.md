# Generative AI Learning Projects

Hands-on projects exploring Generative AI, Large Language Models (LLMs), prompt engineering, embeddings, and AI-powered application development using Python.

## About This Repository

This repository documents practical implementations and projects developed while learning Generative AI concepts and technologies.

It builds on Python and Data Science fundamentals and progresses toward developing reliable applications powered by Large Language Models.

## Topics Covered

- Generative AI Fundamentals
- Large Language Models (LLMs)
- Prompt Engineering
- LLM API Integration
- Text Generation and Summarization
- Structured Outputs
- Embeddings and Semantic Similarity
- Conversational AI Applications
- LLM Evaluation
- AI Safety and Responsible Development

## Technologies

## Learning Objectives

1. Understand how Generative AI and LLMs work.
2. Write and evaluate effective prompts.
3. Integrate LLMs into Python applications.
4. Generate reliable structured outputs.
5. Build practical AI-powered applications.
6. Evaluate application quality and handle limitations responsibly.

## Project Standards

Completed projects will aim to include documentation, setup instructions, example inputs and outputs, testing, evaluation, and relevant safety considerations.
